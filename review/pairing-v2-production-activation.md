## One decision in Root Setup

Root Setup should select one protected pairing policy, disabled or v2 with decision proof. Keep the decision in the authorized provisioning workflow. Let `RuntimeConfigurationBundle` encode its exact value with the existing transport pin. The enabled selection always emits both flags as true. Preserve the default bytes when no activation is authorized. Retain the choice with the provisioning inputs so first publication, retained Setup, and retry derive the same bytes. A LAN rollout also requires an explicit protected LAN scope.

Use that writer for a selected attended installation first. Activate the production default only after installed and LAN evidence and user approval. Existing published installations need a deliberate Setup transition against their verified protected record. Renewal should preserve the current policy. An explicit cold disable must survive renewal and Setup retry. [Startup config](../macos/core/Sources/RemozioCore/AuthorityPairingSetup.swift#L13) · [Retained Setup](../macos/core/Sources/RemozioCore/RuntimeConfigurationBundle.swift#L108)
