# macOS pairing deadline and commit results

Design for [#859](https://github.com/rock3r/remozio/issues/859) based on main `062e9ad509e6af7eeb006e9f0426d423de00a51b`. Land the clock fix first. It changes only the Mac session and its presentation. The second PR changes the Mac app–Root exchange and needs its own compatibility and durability tests.

## PR 1 — Count sleep toward pairing expiry

**Cause.** The installed app samples `ProcessInfo.systemUptime`, which Apple defines as time the system has been awake. Root uses `AuthorityClock`, which wraps the existing `SleepInclusiveClock` sampler. On macOS that sampler reads `mach_continuous_time()`. Consequently, the app can still show time or enable an action when Root already considers the attempt expired. [App clock](../macos/core/Sources/RemozioCore/MacPairingSession.swift#L108-L119), [systemUptime](https://developer.apple.com/documentation/foundation/processinfo/systemuptime), [Root clock](../macos/core/Sources/RemozioCore/AuthorityClock.swift#L4-L20), [macOS sampler](../host/shared-core/Sources/RemozioHostCore/SleepInclusiveClock.swift#L33-L57).

**Behavior.** Reuse that sampler with an app-local deadline and keep the clock injectable. Fail closed on a sampling or conversion error. Keep the V2 deadline anchored before the Root open call. At staging, cap it with the shorter of the advertised lifetime and the remaining signed wall-clock window. Compare elapsed time after staging, so later wall-clock changes cannot extend the attempt. Keep the existing signed-window checks and Root enforcement. [V2 deadline](../macos/core/Sources/RemozioCore/MacPairingSession.swift#L181-L198), [staging deadline](../macos/core/Sources/RemozioCore/MacPairingSession.swift#L259-L280).

At or past the deadline, publish `.expired`, clear action availability, and release the uncommitted session through existing cleanup. Recheck after an awaited status read before accepting candidates or proof. Route confirm and commit expiry through the same transition so the sheet can render it from the snapshot. Recheck after authorization and immediately before submission. The existing poll refreshes the sheet after wake. Once Root submission can occur, a later deadline cannot determine the commit outcome. [Status read](../macos/core/Sources/RemozioCore/MacPairingSession.swift#L220-L240), [action checks](../macos/core/Sources/RemozioCore/MacPairingSession.swift#L282-L323), [sheet polling](../macos/app/App/PairingSheet.swift#L105-L119).

**Tests.** Extend the injected-clock fixture with a sleep-sized elapsed jump, independent wall-clock changes, exact deadline equality, and both orders of the V2 and staging bounds. Exercise legacy and V2 sessions. Suspend a status read or the administrator response across expiry. Assert the expired snapshot, disabled actions, and zero Root commit calls. Exercise a clock read failure. In an attended run on the installed stack, sleep past the deadline during comparison or biometric confirmation and verify the sheet after wake. [Existing elapsed deadline fixture](../macos/core/Tests/RemozioCoreTests/MacPairingSessionTests.swift#L285).

## PR 2 — Report a proven Root rejection

**Cause.** The app sets `commitAttempted` before the channel call. The channel already has an `onSend` hook at the XPC dispatch boundary, but commit does not use it. Root's generic reply handler closes the endpoint and returns `nil` on any error. The channel treats `nil` as an invalid reply. The session then maps every failure after its flag to `.outcomeUnknown`. [Session and failure mapping](../macos/core/Sources/RemozioCore/MacPairingSession.swift#L289-L360), [client dispatch](../macos/core/Sources/RemozioCore/AuthorityPairingChannel.swift#L75-L91), [reply decoding](../macos/core/Sources/RemozioCore/AuthorityPairingChannel.swift#L379-L405), [Root reply](../macos/core/Sources/RemozioCore/AuthorityPairingXPCEndpoint.swift#L364-L423).

**Behavior.** Negotiate an opt-in, bounded XPC commit result on the authenticated channel. Keep the legacy selector and its reply semantics for mixed versions. Carry a verified signed receipt on success or a small rejection code bound to the outstanding setup and transcript. Keep the native caller, administrator, transcript, proof, and release-activity checks. Record local failure before dispatch separately using the existing send boundary. Admit a Root rejection only from an explicit pre-mutation path or a transaction that proves no enrollment was committed. An error type alone carries insufficient evidence. The checkpoint can fail after SQLite writes, and receipt retrieval and signing follow the write. A lost reply, uncertain rollback, storage failure, invalid receipt, or unrecognized result after dispatch remains `.outcomeUnknown`. [Root validation](../macos/core/Sources/RemozioCore/AuthorityPairingSetup.swift#L377-L390), [commit and receipt](../macos/core/Sources/RemozioCore/ApprovalRequestCoordinator.swift#L338-L382), [checkpoint boundary](../macos/core/Sources/RemozioCore/CheckpointedJournal.swift#L22-L67).

Show expiry or a localized refusal for proven rejection. Preserve definitive states through close and cleanup. Permit a deliberate new attempt after proven rejection and drain. Keep automatic retry disabled and keep replacement blocked for uncertain outcomes. Preserve the distinction between Mac registration and phone receipt delivery. [Session and close](../macos/core/Sources/RemozioCore/MacPairingSession.swift#L310-L345), [sheet drain](../macos/app/App/PairingSheet.swift#L157-L176).

**Tests.** Cover pre-dispatch failure, authenticated refusal, admitted expiry, and unchanged journal enrollment. Inject checkpoint or receipt failure after a write and verify that a lost, malformed, or legacy `nil` reply stays ambiguous. Cover both mixed-version directions, successful signed receipt, failed phone delivery, and close or re-pair during an outstanding commit. Verify recovery returns only the receipt for the authenticated durable attempt. [Compatibility fixture](../macos/core/Tests/RemozioCoreTests/AuthorityPairingSetupTests.swift#L898), [lost reply fixture](../macos/core/Tests/RemozioCoreTests/AuthorityPairingSetupTests.swift#L1660), [checkpoint fixture](../macos/core/Tests/RemozioCoreTests/AuthorityPairingSetupTests.swift#L4151), [close fixture](../macos/core/Tests/RemozioCoreTests/MacPairingSessionTests.swift#L194).
